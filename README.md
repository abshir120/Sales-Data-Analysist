# Sales Data Analysis Dashboard

## Project Overview
This project analyzes sales data using SQL Server and Microsoft Power BI.

## Objectives
- Analyze total sales and quantities.
- Compare sales across cities.
- Explore product and category performance.
- Create an interactive dashboard using a city slicer.

## Tools Used
- SQL Server
- Microsoft Power BI
- DAX

## Key Results
- Total Sales: 4,885
- Total Quantity Sold: 114
- Highest Sales City: Hargeisa

## Dashboard Features
- Total Sales card
- Total Quantity card
- Average Sale card
- Sales charts
- Interactive City Slicer

## Skills Demonstrated
SQL queries, data analysis, data visualization, and dashboard development.
